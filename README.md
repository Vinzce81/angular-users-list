# UserShowcase

This project is a small angular application that shows a list of users and searches among them. Sorry for the eyes, no CSS.

It simulates a realistic flow:
- user input
- searchEvent.emmit
- pageComponent
- facade.search()
- BehaviorSubject
- debounceTime
- switchMap
- API
- store.setUsers()
- users$
- async pipe
- UI update

## Development server

To start a local development server, run:

```bash
ng serve
```

Once the server is running, open your browser and navigate to `http://localhost:4200/`. The application will automatically reload whenever you modify any of the source files.
